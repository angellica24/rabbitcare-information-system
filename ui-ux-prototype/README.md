# UI/UX Prototype – RabbitCare

## Overview

This directory contains the UI/UX design documentation and interactive prototype of the RabbitCare Information System.

The prototype was developed using Figma to illustrate the proposed user interface, navigation structure, and user interactions within the RabbitCare application.

## Design Objectives

The UI/UX prototype aims to:

- Provide an intuitive and user-friendly interface.
- Support the operational workflows of rabbit clinic services.
- Organize information and system functions based on user roles.
- Visualize the proposed system features and user interactions.
