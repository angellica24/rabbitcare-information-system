# Project Requirements Documentation

This directory contains the business and system requirements documentation for the RabbitCare Information System.

## Available Documents

| Document | Description |
|---|---|
| BRD | Business Requirements Document |
| MRD | Market Requirements Document |
| PRD | Product Requirements Document |
| SRD | Software Requirements Document |

These documents define the project background, business objectives, product requirements, system specifications, and functional scope of RabbitCare.
