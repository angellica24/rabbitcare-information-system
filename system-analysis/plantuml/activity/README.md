# Activity Diagrams

This directory contains the Activity Diagrams of the RabbitCare Information System.

The diagrams illustrate the workflows, business processes, and activity sequences involved in the system, including interactions between users and system components.

## Diagram Overview

The Activity Diagrams describe the operational workflows and business logic of RabbitCare, providing a visual representation of how different processes are performed within the system.

## Source Files

All diagrams are provided in PlantUML (.puml) format to support further editing and visualization.
