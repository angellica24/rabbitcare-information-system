# Class Diagram

This directory contains the Class Diagram of the RabbitCare Information System.

The diagram illustrates the system's structural design, including classes, attributes, operations, and relationships between different system entities.

## Diagram Overview

The Class Diagram provides an overview of the system architecture and object-oriented structure, supporting the understanding of data entities and their interactions within RabbitCare.

## Source Files

The diagram is provided in PlantUML (.puml) format to support further editing and visualization.
