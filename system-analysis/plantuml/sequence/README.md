# Sequence Diagrams

This directory contains the Sequence Diagrams of the RabbitCare Information System.

The diagrams illustrate the interactions and communication flows between system actors, application components, and supporting processes throughout different system operations.

## Diagram Overview

The Sequence Diagrams describe how requests, responses, and system processes are executed in a specific sequence.

These diagrams provide a clearer understanding of system behavior and interactions between users and the RabbitCare application.

## Source Files

All diagrams are provided in PlantUML (.puml) format to support further editing and visualization.
