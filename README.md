# RabbitCare – Rabbit Clinic Management Information System

## Project Overview

RabbitCare is an academic group project focused on the analysis and design of an information system for rabbit clinic and care management.

The project aims to design an integrated information system that supports clinic operations, including customer management, rabbit patient records, appointment booking, payment administration, medical examination, and grooming services.

## Project Objectives

- Analyze business processes and operational requirements.
- Identify system requirements based on user needs.
- Design structured business processes and system workflows.
- Develop system models and database design documentation.
- Create a UI/UX prototype to illustrate the proposed system.

## System Roles

The proposed system involves several user roles:

- **Owner:** Manages rabbit profiles, appointments, payments, and health information.
- **Admin:** Manages bookings, payment validation, check-in, and staff assignments.
- **Doctor:** Handles patient examinations and medical records.
- **Groomer:** Manages grooming services and related patient records.
